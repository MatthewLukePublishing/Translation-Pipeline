# Tests

Run the public, deterministic, non-Adobe suite from the repository root:

```powershell
npm test
```

The runner syntax-checks all maintained JavaScript and PowerShell modules, then exercises shared data contracts, bounded QA accounting, workbook-staleness protection, Codex-harness model selection, recursive diagram discovery, Portuguese-column isolation, ICML safety, transaction recovery, path containment, and public-distribution privacy rules. Fixtures are synthetic.

Regression coverage also includes fresh source-package hashes, literal workbook
round-trips, line-break tokens, targeted rechecks, contextual glossary ambiguity,
official unit-name boundaries, and completion evidence tied to the exact imported
workbook and finalized document. Mocked Adobe lifecycles verify bounded calls,
read-only audits, preservation of unsaved work, and text-only link updates.

The suite does not use private workbooks, network access, credentials, paid services, model queries, Microsoft Office, InDesign, or Illustrator.
